一、项目背景与产品定位

1.1 背景

传统教辅使用模式存在三大痛点：

痛点具体表现
千人一面同一本教辅，成绩好的学生觉得太简单，成绩弱的学生觉得太难，都无法精准匹配
缺乏跟踪学生做了题，错了就错了，没有系统记录薄弱点，同样的错误反复犯
被动学习学生按章节顺序刷题，不知道自己该练什么、不该练什么，效率低下

而现有 BingoMate 产品已具备拍照识别、错题分析、薄弱项判定、学情同步等核心能力，但教辅内容仍停留在"纸质书→人工看"的阶段，智能体无法直接调用教辅内容进行个性化引导。

1.2 产品定位

不是把纸质书变成电子书，
而是把教辅变成智能体可调用的知识资产
孩子使用时只需说一声，智能体根据学情自动引导学习

孩子使用流程变化对比：

维度传统模式智能教辅模式
打开方式孩子自己翻书找页数孩子说"我要学xx教辅"
做题顺序按章节顺序从头到尾智能体根据学情安排最优路径
做错之后自己看答案，不一定看懂智能体名师1v1讲解+变式巩固
复习安排自己翻错题本智能体按遗忘曲线自动调度
家长视角不知道孩子学了什么实时看到教辅进度+掌握率

二、智能教辅数据包（产品概念）

2.1 什么是智能教辅数据包？

每本教辅转化后形成一个独立的数据包，包含五类核心内容：

数据资产通俗理解智能体怎么用
知识点图谱教辅的"目录升级版"——章→节→知识点→考点，以及知识点之间的前后依赖关系定位薄弱点时，自动找到前置知识点一起补
标签化题库每道题都打上了标签：难度、知识点、题型、适合哪类学生根据学生分层推荐不同难度题目
解题方法库教辅中"方法总结""易错提醒"等精华内容的集合讲解时引用方法库，告诉学生"这类题通用的解法是什么"
变式题生成规则每道典型题可以怎么改（改数据、改条件、改问法）学生做对一道题后，自动生成变式题检验是否真会
讲解风格模板三种讲解风格的话术模板根据学生分层自动切换讲解风格

2.2 数据包与 BingoMate 的融合方式

数据包不独立运行，而是嵌入现有 BingoMate 学情体系，作为智能体的"知识弹药库"：

孩子说："我想做数学同步训练"
↓ BingoMate 智能体
  ├── 读取学生档案（分层/薄弱项/学习风格）
  ├── 加载对应教辅数据包（知识点图谱+题库+方法库）
  ├── 结合学情计算最优路径（跳过已掌握、聚焦薄弱项）
  └── 生成个性化学习任务 → 引导孩子学习

三、学生画像与分层体系

3.1 学生档案结构（1+N 架构）

一个基础档案 + 不断更新的动态标签：

📋 基础信息层（建档时录入，可修改）
  • 姓名、年级、学校、教材版本
  • 升学目标、每日学习时长、性格偏好
  • 预设薄弱项、AI 反馈规则（给思路还是给答案）
📊 学情数据层（每次做题后自动更新）
  • 知识掌握度：每个知识点标注为"已掌握/基本掌握/薄弱/严重薄弱/未接触"
  • 六维能力：基础知识、计算能力、逻辑推理、阅读理解、解题规范、应试心态
  • 学习习惯：学习节奏、错误模式（粗心型/知识型/思路型）、提升速度
  • 错题与薄弱项库：按学科→章节→知识点→题型四级归档，按遗忘曲线调度复习
🏷️ 分层标签层（系统每周自动判定）
  • A层（优秀生） 估占20%：综合能力强，需要挑战更高难度
  • B层（中等生） 估占50%：基础尚可但有明显薄弱点，需要精准补弱
  • C层（薄弱生） 估占30%：基础薄弱，需要重建信心和地基

3.2 分层判定逻辑

判定维度权重说明
近期作业/试卷正确率40%近2周加权平均
已掌握知识点占比25%绿色知识点占全部的比例
严重薄弱项数量20%红色薄弱项越少越好
六维能力综合评分15%六项能力的平均分

分层不是一成不变的，每周根据最新学情数据重新评估，学生可升层或降层。

3.3 三种分层学习模式对比

对比维度A层·拓展深化B层·巩固提升C层·基础重建
学生特征基础扎实，常规题正确率高，容易"吃不饱"基础基本掌握但不扎实，同样错误反复犯概念模糊，公式记不住，做题靠猜，信心不足
核心策略举一反三、竞赛拓展、跨章综合精准补弱、变式训练、方法归纳回归课本、阶梯递进、信心重建
教辅使用方式教辅为底，向外拓展
快速通关基础题，聚焦压轴题		教辅为主线，精准打击
不从头刷，只做薄弱点对应的题		课本优先，教辅辅助
先确保课本例题100%会做
题目难度配比基础:提升:压轴 = 2:3:5基础:提升:压轴 = 4:4:2基础:提升:压轴 = 7:2:1
讲解风格启发式——引导思考，不给答案引导式——先给思路再逐步展开陪伴式——慢节奏、多鼓励、全拆解
家长参与程度轻度，看报告即可中度，确认任务、查看进展深度，每日推送"陪伴指南"和"鼓励话术"
目标保持A层，冲击竞赛3-6个月晋升B→A3-6个月晋升C→B

四、产品交互流程设计

4.1 核心交互理念

"孩子说一声，智能体带路"
孩子不需要自己翻书找题、不需要自己决定先做哪章，直接通过自然语言与智能体对话，智能体根据学情自动匹配教辅内容

4.2 典型交互场景

场景一：启动教辅学习

👦 孩子：我想学《数学同步训练》
🤖 智能体：好的！你上次做到第22章"一元二次方程"，当前薄弱项是"公式法"（正确率45%），我们先从第22.2节"公式法解方程"开始，预计需要25分钟，准备好了吗？

场景二：做教辅中的题

👦 孩子：开始吧
🤖 智能体：请打开教辅第38页第7题，用公式法解方程 2x²-5x+2=0。这道题考查"公式法"和"判别式"，是你当前的薄弱项。给你5分钟，做完告诉我答案
👦 孩子：我算出来了，x=2和x=1/2
🤖 智能体：完全正确！🎉 来，再做一道变式题巩固一下——解方程 3x²-7x+2=0

场景三：薄弱项攻克

🤖 智能体：这道题你又做错了，我们来看一下为什么。你的薄弱点是"判别式符号判断"。注意：Δ<0时方程无实数根，不要急着代入公式。我帮你切换到"基础重建"模式，重新讲一遍判别式的概念...
🤖 智能体：现在来做一道课本原题，确认你理解了

场景四：学习总结

👦 孩子：今天学完了
🤖 智能体：今日学习总结——
✓ 完成题目：6道（对4道，错2道）
✓ 攻克薄弱项："公式法"从红色→黄色
✓ 新增薄弱项："判别式符号判断"（黄色）
✓ 明天建议：继续第22.2节，重点攻克"判别式"
已同步到家长工作台，快去告诉妈妈你今天的进步吧！

4.3 智能体引导规则

学生状态智能体行为
首次使用教辅自动检测学情档案，推荐最需要开始的章节
基础扎实的学生跳过已掌握章节，直接进入薄弱项
薄弱项集中的学生降级到对应章节，先补前置知识再前进
连续做对（3题以上）提升难度，生成变式题或挑战题
连续做错（2题以上）切换讲解模式，降低难度阶梯递进
做完一个单元自动生成单元复习任务
整本教辅学完生成综合测评，输出掌握率报告

4.4 与现有 BingoMate 流程的衔接

现有 BingoMate 功能智能教辅如何增强
拍照→识别→分析错题识别后，自动从教辅数据包中检索同类题推送

六、产品设计原则

6.1 核心原则

  1. 无缝衔接：不改变已有 BingoMate 使用习惯，原有拍照、分析、同步流程全部保留
  2. 渐进增强：教辅数据包是增量能力——没有数据包时 BingoMate 照常运行，有数据包时自动升级体验
  3. 数据驱动：学情数据越丰富，智能体引导越精准；前期数据少时先按默认路径走
  4. 隐私优先：所有数据存储在 BingoClaw 设备本地，不上传云端

6.2 技术架构理念（不涉及具体实现）

  • 大模型负责"讲解生成"和"逻辑推理"
  • 结构化数据库负责"精准检索"和"内容供给"
  • 两者通过检索增强生成（RAG）结合，而不是把所有内容都塞给大模型

6.3 与 BingoMate 现有功能的关系

现有功能智能教辅如何利用
拍照识别识别学生作业后，自动匹配教辅数据包中的对应题目
错题归档错题自动关联到教辅的章节和页码
薄弱项判定在教辅的知识图谱中定位薄弱知识点
名师讲解讲解时引用教辅数据包中的方法库和解析
学情同步家长看到的不只是错题，还有教辅进度和掌握率
生成练习题优先从教辅数据包中选题，保证与教辅内容一致

八、待讨论议题

本章列出会上需要明确决策的产品设计问题，各方讨论确认后再写入正式方案。

📌 议题一：学生初始水平定位方式

1) 现有方案的潜在问题

当前流程假设学生启动系统时能准确自报水平（"我是中等生""我数学不好"），但实际存在两个明显漏洞：

问题具体表现后果
学生自我认知不准确 小学生/低年级学生普遍高估或低估自己；部分学生会为了"显得好"或"显得弱"而虚报 初始分层判断错位，智能体推送的题目难度全部跑偏
缺乏统一排名标准 目前仅按"优良中差"主观划分，且各地、各校标准不同——A 校的"中等"可能是 B 校的"优秀" 无法跨地区、跨学校做横向比对，分层失去客观参照

2) 建议方案：启动时先做一张摸底卷

不靠学生自报，启动系统后先出一张难度适中的各题型综合卷
用摸底成绩作为初始分层依据，客观、可比、可复盘

摸底卷设计要点：

维度说明
难度中等偏基础（保证大多数学生能做出 60%~80%）
题型覆盖本学科各题型（选择、填空、计算、应用、阅读理解等）
题量控制在 20~30 分钟内完成（避免学生产生抵触）
评估目标测出基础掌握度 + 六维能力初始值 + 知识图谱起始节点
结果应用直接写入学生档案，作为 A/B/C 分层的客观依据

📌 议题二：教辅类型的划分与差异化设计

1) 现状问题

目前方案把所有教辅当作"一类资源"统一处理，没有区分其用途。但实际上不同教辅的功能定位差异巨大：

类型典型场景学生使用痛点
复习巩固类 学期中的同步练习册、单元测试卷、期中期末真题 错题反复出现，同样的薄弱点讲完一遍下次还是错
学习预习类 寒暑假预习书、新学期衔接教材、培优讲义 新知识点枯燥难懂，自学容易卡壳放弃

两类教辅的核心目标和最佳使用节奏完全不同，智能体的引导策略也应当有所区分。

2) 建议方案：按教辅类型差异化设计引导策略

维度📘 复习巩固类📗 学习预习类
核心目标 解决孩子已学知识的薄弱点，确保掌握 让孩子顺利接触新知识，建立初步认知
智能体角色 "错题医生"——诊断 → 讲解 → 变式巩固 "预习导师"——引入 → 启发 → 鼓励探索
题目难度 从薄弱点出发，由易到难逐步攻克 从基础概念开始，难度递进慢、引导多
讲解风格 直奔错因、方法导向，少铺垫 故事化、生活化类比，多鼓励
使用节奏 按学情动态安排，可跳跃式刷题 按章节顺序推进，不建议跳章
反馈重点 薄弱点变化趋势、错题掌握率 新知识吸收进度、概念理解度
家长视角 "今天攻克了几个薄弱点" "今天预习到第几章、吸收如何"
