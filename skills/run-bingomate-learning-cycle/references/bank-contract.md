# 题库契约 —— 教辅资产的结构、定位与缺失降级

本 skill **自包含只读题库资产**，不依赖兄弟 Skill 的目录结构。

本文件定义三件事：资产长什么样、怎么找到它、找不到时怎么办。

题库、锚题表与考点边界都在本 skill 的 `../assets/`，理由见第五节。

---

## 一、资产清单

| 资产           | 文件                                                                                         | 缺失时                         |
| -------------- | -------------------------------------------------------------------------------------------- | ------------------------------ |
| 教辅题库       | `../assets/questions/unit1_extracted_with_answers.json`、`unit2_extracted_with_answers.json` | 进入降级模式，见第五节         |
| 锚题定位表     | `../assets/anchor_bank.json`                                                                 | 非致命，去重精度下降，见第四节 |
| 考点与词汇边界 | `../assets/scope-digest.md`                                                                  | 不会缺失                       |

## 二、题库文件结构

```
{
  "metadata": { "source_file", "book", "subject", "grade", "version", "unit", "unit_title", "extracted_at" },
  "sections": [
    {
      "period":  "第3课时",                   // 内部回源粒度；对学生只说 Unit
      "section": "Section A (Grammar Focus)",  // 教材小节，展示用
      "exercises": [
        {
          "exercise_no": "I",                  // 罗马数字，节内唯一
          "part": "基础夯实",
          "type": "单项选择",
          "questions": [ ... ],
          "answer": { "1": "B. by", "2": "A. repeat" }
        }
      ]
    }
  ]
}
```

单元名不在 `sections` 里，取自 `metadata.unit`（`"Unit 1"` / `"Unit 2"`），与画像的 `scope.units` 取值一致。

### `part` —— 难度层

| 取值                    | 含义                             | 本 skill 是否取用 |
| ----------------------- | -------------------------------- | ----------------- |
| `基础夯实`              | 单题，约 30 秒作答               | 是                |
| `能力提升`              | 整篇材料，含多个计分点，5–8 分钟 | 是                |
| `自主检测`              | 单元自测卷                       | 否                |
| `写作实例` / `写作实战` | 范文与写作训练                   | 否，无法自动判分  |
| `null`                  | 抽取时没落下标注                 | 否                |

**只有前两种进候选池。** 其余一律跳过，不猜、不补标。

### `type` —— 题型，决定能力维度

`type` 到能力维度的映射如下，与本 Skill `profile_engine.py` 的 `ABILITY_MAP` 一致：

| 能力维度 | 教辅题型                                                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 词形变化 | `用括号内所给词的适当形式填空`、`根据句意和首字母提示写出所缺的单词`、`从方框中选出合适的词，并用其适当形式填空`、`从方框中选出合适的词或短语，并用其适当形式填空` |
| 汉英转换 | `根据汉语意思完成句子，每空一词`、`按要求完成句子，每空一词`                                                                                                       |
| 语法辨析 | `单项选择`、`语法填空`                                                                                                                                             |
| 篇章理解 | `阅读理解`、`完形填空`、`任务型阅读`、`任务型阅读（选句填空）`、`短文填空`、`短文还原`、`补全对话`                                                                 |

题库里另有 8 种 `type` 不在映射内：3 种听力（需音频）、5 种书面表达（无法自动判分）。**遇到映射外的 `type` 一律跳过，不要猜它属于哪一维。**

### `questions[]` —— 题目

| 字段         | 类型               | 说明                                                    |
| ------------ | ------------------ | ------------------------------------------------------- |
| `no`         | int                | 题号，**在整个课时内连续**，不是练习内从 1 开始         |
| `stem`       | str                | 题干，填空位用连续下划线表示，空位数 = 下划线组数       |
| `options`    | {A-D: str} \| 缺失 | 选择题才有                                              |
| `chinese`    | str \| 缺失        | 中译英题的中文提示                                      |
| `given_word` | str \| 缺失        | 括号填空题给出的原形词                                  |
| `source`     | str \| null        | 中考出处，如 `2024北京中考改编`。有值说明干扰项经过设计 |

**`questions` 可能是空数组。** 有若干个练习只抽到了 `type` 与 `answer`、没抽到题干。建候选池时按 `len(questions) > 0` 过滤，不要试图从 `answer` 反推题目。

### `answer` —— 标准答案

`answer` 是 `{"题号": "答案"}` 的字符串映射，键是 `no` 的字符串形式。

**书面表达类练习的 `answer` 是一个整串范文，不是 dict。** 这类练习本来就不进候选池，遇到 `answer` 不是 dict 时直接跳过。

答案串的四种写法必须都能读懂：

| 写法       | 例                                                            | 含义                                 |
| ---------- | ------------------------------------------------------------- | ------------------------------------ |
| 选择题     | `"B. by"`                                                     | 字母、选项文本、完整串三种回答都算对 |
| 单空填空   | `"aloud"`                                                     | 唯一答案                             |
| 多空填空   | `"by watching English TV programs"`                           | 多个空的答案按顺序用空格连接         |
| 分号分槽   | `"if/whether; they; will"`                                    | 分号分隔各个空                       |
| 斜杠可替换 | `"practice/practise speaking"`、`"will take place / be held"` | 该位置有多种正确写法                 |

斜杠有两种粒度：**词内斜杠**（`practice/practise`）表示这一个词可替换；**两侧带空格的斜杠**（`/`）表示整段可替换。

把这些展开成 `acceptable_answers` 数组时，两种粒度都要展开，展开结果全部收进数组。展开不确定时保留原串并在任务包里标注，**不要只取斜杠左边那个**。

## 三、锚题定位表 `anchor_bank.json`

```
{
  "version": 3,
  "description": "...",
  "note": "...",
  "items": [
    {
      "id": "u1-method-by",                 // 稳定 qid，与画像 exclude_qids 对得上的唯一凭据
      "source_file": "questions/unit1_extracted_with_answers.json",
      "unit": "Unit 1",
      "locator": { "period": "第3课时", "exercise_no": "I", "question_no": 3 },
      "knowledge_point": "how 引导的 by 表方式"
    }
  ]
}
```

**只有这 12 道锚题有稳定 `qid`，题库里其余题目没有。** 这决定了下一节的去重方式。

---

## 四、定位与去重

### 定位四元组

题库里的任意一道题由 `unit + period + exercise_no + question_no` 唯一确定。任务包里用结构化形式：

```json
"locator": { "unit": "Unit 1", "period": "第3课时", "exercise_no": "II", "question_no": 7 }
```

需要写成单个字符串时（例如塞进 `exclude_qids`），用斜杠拼接：`Unit 1/第3课时/II/7`。一篇「能力提升」材料的多个小题合并成一条：`Unit 1/第3课时/III/8-10`。

### 去重规则

画像的 `exclude_qids` 里混着两类 id，分别处理：

| id 形态                    | 来源                  | 匹配方式                                                 |
| -------------------------- | --------------------- | -------------------------------------------------------- |
| `u1-method-by` 这类语义串  | 教辅锚题              | 在 `anchor_bank.json` 里查到 `locator`，换算成四元组再比 |
| `gen-u1-by-03` 这类        | 诊断时的 LLM 生成题   | 题库里不存在，**忽略**，不必匹配                         |
| `Unit 1/第3课时/II/7` 这类 | 本 skill 上一轮写回的 | 直接按四元组比                                           |

`anchor_bank.json` 读不到时，语义串 id 无法换算成定位，**结果是那 12 道锚题可能被重复推送**。这是可接受的降级：记一条 `data_gaps`，继续跑，不要因此中止。

做错过的题不排除。`exclude_qids` 只表示"用过"，订正本身有价值。

## 五、路径解析与降级

### 解析顺序

按顺序取第一个能读通的：

1. 调用方显式传入的题库目录（入参 `bank_dir`）
2. 环境变量 `BINGOMATE_BANK_DIR`
3. 本 skill 自带的 `../assets/` —— **默认命中这一条**
4. 都不可用 → 降级模式

「读得通」的判据是三条全过：文件存在、JSON 能解析、`sections` 是非空数组。任何一条不过按不可用处理，**不要吞掉解析错误当成空题库**——把错误信息写进 `data_gaps`。

单元文件可以部分可用。Unit 1 读到、Unit 2 读不到时，候选池只用 Unit 1，`data_gaps` 记明缺哪个单元，不整体降级。

### 降级模式的行为契约

题库完全不可用时，本 skill **仍然产出完整任务包**，但以下几条同时生效：

| 项               | 正常模式                        | 降级模式                                                 |
| ---------------- | ------------------------------- | -------------------------------------------------------- |
| `bank_available` | `true`                          | `false`                                                  |
| 题目来源         | 教辅原题为主，变式补足          | **全部为生成题**，`source` 一律 `generated`              |
| 考点边界         | `assets/scope-digest.md`        | 同左，**约束不放松**                                     |
| 定位标注         | 写 `locator`                    | **不写 `locator`，一律为 null**                          |
| 学生可见出处     | 只说所属 Unit                    | 只说考点，不编造 Unit、课时与题号                        |
| 自检             | 变式题过一遍自检                | **每道题都过一遍自检**，见 `variant-generation.md`       |
| `data_gaps`      | 按实记录                        | 必须含一条「题库不可用，全部题目为生成题，未经人工质检」 |

**降级模式下绝不允许凭记忆编造课时与题号。** 编一个"Unit 1 第 3 课时第 2 题"出来，学生翻开教辅发现对不上，这比不给出处严重得多。这也是各层手册里的话术示例在降级模式下不能照抄的原因。

各层受降级影响的程度不同，处置写在各自手册里。

## 六、几条不做的事

- **不写运行时副本。** 题库随本 skill 一起打包；运行时只读，不把修改后的副本写回资产目录。
- **不修改题库。** 只读。补标注、修答案都不是本 skill 的职责，发现问题写进 `data_gaps`。
- **不猜缺失的标注。** `part` 为空、`type` 不在映射表、`questions` 为空，一律跳过而不是推断。
- **不用页码。** 题库没有页码字段，任何页码都是编造的。对学生和家长只说到单元。
