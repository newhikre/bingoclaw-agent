# 变式题的产出

## 一、原题优先，原题不够再生成

教辅原题的题干与答案经过人工质检，生成题不具备这层保障，因此顺序固定：先把候选池放宽到同单元同考点的其他课时，再放宽到相邻能力维度，两者都填不满配比时才生成变式题。

进入任务包的变式题一律标 `source: "variant"`，让下游知道这道题没有人工背书。

**降级模式下这一节整节失效。** 题库读不到时没有原题可依，全部题目直接进第二节的生成流程，`source` 标 `generated`（不是 `variant`，因为没有可派生的原题），`derived_from` 为 `null`。此时第四节的自检要跑满每一道题，不只是变式题。

## 二、五条生成约束

这五条与当前 Skill 生成诊断题时的约束一致。链路两端用同一套标准，学生才不会感到题目风格突然变了。

**第一，照搬教辅题型。** 从 `ABILITY_MAP` 覆盖的 15 种 `type` 里选（`用括号内所给词的适当形式填空`、`单项选择`、`根据汉语意思完成句子，每空一词`、`语法填空`、`补全对话` 等），格式与教辅一致：中译英题给出中文与下划线空位并注明"每空一词"，括号填空题把原形词放在括号里。自创题型会让学生在考试里认不出来。

**第二，考点与词汇不得越出 `assets/scope-digest.md`。** 生成前先读这个文件，它内置在本 skill 里，题库读不到时它仍然可用，**降级模式下约束一分不减**。这是硬边界——考点必须落在文件列出的语法结构上，词汇按文件开头的三类规则处置。最常见的失误是为了让题目有意思一点，用了 Unit 3 的 wh- 引导宾语从句，或者塞进一个学生没学过的单词，结果测的不是本次锚点而是词汇量。

**第三，附一道同层同考点的教辅原题作难度样例。** 生成时把那道原题放在上下文里对照，防止难度漂移。新题与原题处于同一 `part`，刻意的降阶或升阶变式除外。

**第四，选择题优先出带诊断性干扰项的。** 每个错误选项对应一种典型误解，学生选了哪个就知道他错在哪儿。锚点来自画像 `misconceptions` 时，把那条误解直接做成其中一个干扰项——这是验证误解是否还在的最快方式。

> 锚点：by 后的动名词误作不定式
> `She improved her listening ______ English songs every day.`
> A. by listen　B. by listening　C. to listen　D. by listened
> A 对应"记得用 by 但忘了变形"，C 对应"把'通过做某事'理解成目的"，D 对应"混淆 -ing 与过去分词"

**第五，必须产出 `acceptable_answers` 数组。** 英语填空常有多解，单一答案会把对的判成错的。教辅原题的答案串本身也带多解写法（斜杠、分号分槽），展开规则见 `bank-contract.md` 第二节，生成题要按同样的粒度展开：

| 题干 | 可接受答案 |
|---|---|
| `I wonder ______ he will come.` | `if`、`whether` |
| `Please read ______ (loud).` | `aloud`、`loudly` |
| 选择题 | `B`、`B. by`（字母与完整选项都收） |
| `He goes to school ______ ______.`（乘公交） | `by bus`、`by buses` 不收（固定搭配用单数零冠词） |

拿不准哪些答案成立时，把这道题降级为原题——多解判错一次，学生对系统的信任就掉一截。

## 三、按规则改编

有原题可依时优先改编而非从零生成。三类规则：

| 规则类型 | 做法 | 例 |
|---|---|---|
| 改词 | 只更换实词，句子结构不动 | `by watching English movies` → `by making word cards` |
| 改情境 | 换一个学生熟悉的场景，考点不动 | 学习方法 → 交通方式，`by bus` 仍考 by |
| 改问法 | 题干不动，更换题型外壳 | 括号填空 → 中译英 → 单项选择 |

改词时唯一容易出问题的地方是**换完之后搭配不再自然**。`by making word cards` 成立，`by making a bus` 不成立。换的是实词，但要连搭配一起验。

改情境时保持认知负荷不变：场景取学生熟悉的类型（学习、交通、节日、家务），不使用需要额外背景知识的题材。

## 四、进入任务包前的自检

每一道变式题都要自己完整做一遍并逐项核对。估计能过不算过。

- [ ] 答案唯一，或全部可接受答案都已写进 `acceptable_answers`
- [ ] 空格数与答案词数对得上（"每空一词"的题尤其容易多写一词）
- [ ] 考点仍是原题那个考点，没有换成另一条语法
- [ ] 考点落在 `assets/scope-digest.md` 列出的语法结构内，词汇不越三类规则
- [ ] 时态、人称、单复数在句内自洽
- [ ] 中译英题的中文与英文答案严格对应，没有多译或漏译
- [ ] 选择题的三个干扰项都对应一种可解释的误解，没有明显不成立的凑数项
- [ ] 题干表述通顺，没有歧义

任何一条不通过时换词重来。推送一道有问题的题给学生，损失的不只是这一道题的时间——学生会开始怀疑系统给的题是否可靠，之后自己做错时也会先怪题目。

反复改都得不到干净的题时，说明这个改编方向不成立，换一条规则或退回去使用原题。

自检通过后在任务包里标 `self_check_passed: true` 与 `in_scope: true`，两者缺一不可。

**降级模式下自检跑两遍。** 第一遍按上面的清单查，第二遍只查考点边界——逐词对照 `assets/scope-digest.md`，确认没有一个考点越界。正常模式下还有教辅原题兜底，一道生成题出问题不至于毁掉整包；降级模式下整包都是生成题，一处越界就是系统性的。

## 五、两种特殊变式

### 降阶变式（C 层与 B 层的救场手段）

把一道题拆小，而非横向改编，有两种做法。

**半步题**把原题拆成两问，第一问只完成原题的第一步。

> 原题：我的老师建议我通过看英文电视节目学英语。
> 　　　My teacher advised me to learn English ______ ______ ______ ______ ______.
> 半步题：(1) "通过……的方式"用哪个介词？填在这里：______
> 　　　　(2) 这个介词后面的 watch 要变成什么形式？______

**提示式脚手架**保留完整句子，只挖掉关键的那一处，并把规则写在旁边。

> `She practices English by ______ (talk) with her friends.`
> 提示：by 后面的动词一律加 -ing

脚手架题的用法是扶着走一遍，用完之后立刻回到完整题再做一道，否则学生只学会了填空。

### 升阶变式（A 层专用）

在原题基础上加条件、换角度，或把两个单元的考点串起来。

> 原题：I know that the Water Festival is really fun.
> 升阶：把这句话改成感叹句，用 What 和 How 各写一遍
> 再升阶：用一个含宾语从句的句子说明你为什么觉得它有意思，并在句中用上 `by doing` 结构

升阶变式同样要过第四节的自检。这类题最容易出现的问题是**改完之后有多种同样正确的写法**，`acceptable_answers` 必须把它们都列出来，或者把题目改成开放题并在任务包里标明按要点给分。

## 六、标注

每道变式题在任务包里都带上它的来历，下游据此追溯和质检。

```json
{
  "source": "variant",
  "derived_from": { "unit": "Unit 1", "period": "第3课时", "exercise_no": "II", "question_no": 7 },
  "rule": "改情境",
  "purpose": "验证真会",
  "acceptable_answers": ["making"],
  "self_check_passed": true,
  "in_scope": true
}
```

`derived_from` 为 `null` 表示这道题是无原题参照直接生成的，这类题进入人工抽检队列。
