# 策略判定模型

## 输入结构

运行时会话 JSON 使用以下结构：

```json
{
  "profile": {
    "grade": "九年级",
    "textbook_version": "人教版",
    "studied_units": ["Unit 1", "Unit 2"],
    "goal": "同步巩固",
    "available_minutes": 20,
    "recent_score": 72
  },
  "selected_question_ids": [
    "u1-transport-by",
    "u1-repeat-word",
    "u1-method-by",
    "u1-unless",
    "u2-exclamation",
    "u2-clause-that",
    "u2-clause-order",
    "u2-clause-if"
  ],
  "answers": {
    "u1-transport-by": "B",
    "u1-repeat-word": "A"
  }
}
```

`recent_score` 可省略，仅用于画像背景和无诊断数据时的低置信度兜底，不覆盖诊断结果。

## 计分

每题先判断正误，再按难度加权：

- 难度 1（基础）：`1.0`
- 难度 2（应用）：`1.25`
- 难度 3（挑战）：`1.5`

输出综合加权正确率、基础题正确率、应用/挑战题正确率，以及按单元和能力维度统计的正确率。

作答时间和自报薄弱项暂不参与本版分层，避免把速度、性格或自我评价误当成学科掌握度。

## ABC 规则

- `A · 拓展挑战`：综合分不低于 80，基础分不低于 80，且至少作答一道应用/挑战题、应用/挑战分不低于 60。
- `C · 稳固基础`：综合分低于 50，或基础分低于 60。
- `B · 巩固提升`：其余情况。

无有效诊断答案时，才使用近期成绩兜底：85 分及以上为 A，60—84 为 B，60 分以下为 C；置信度固定为低。没有近期成绩时默认给出 B 的临时策略，并明确要求补充诊断证据。

不得按 20%/50%/30% 强制分布。结果必须限定为当前学科与已测单元的学习策略。

## 置信度

- 高：至少 8 道有效答案、覆盖至少 2 个单元，同时包含基础和应用/挑战题。
- 中：至少 4 道有效答案，同时包含基础和应用/挑战题。
- 低：不满足以上条件，或仅依赖近期成绩。

## 输出字段

脚本输出 `profile`、`scope`、`scores`、`strategy` 和 `limitations`。其中 `strategy` 包含代码、名称、置信度、判定理由及策略参数。

策略参数固定为：

- A：基础20%、应用40%、挑战40%；快节奏；启发式反馈。
- B：基础40%、应用40%、挑战20%；中等节奏；先给思路再分步提示。
- C：基础70%、应用25%、挑战5%；慢节奏；概念和例题优先、陪伴式反馈。
