# B 层 · 巩固提升

对应上游画像 `strategy.code = "B"`，判定依据是基础夯实达标但能力提升不足，或两者都在中间地带。

## 学生特征

单点知识基本掌握但不扎实，典型特征是同样的错误反复犯——讲完当时懂了，隔两周同类题还是错。问题不在于不会，而在于**会得不牢**：`by + 动名词` 单独考会做，放进一段完形填空里就填成了不定式。

画像的 `error_pattern` 为 `思路型` 时（基础全对、篇章题错）这一层最典型：单点会但整合不会，缺的是把知识点认出来的能力。

核心目标是把「能力提升」的正确率拉到 60% 以上，晋升 A 层。

## 单次任务结构

题量与配比以画像 `next_session` 为准。字段缺失时的兜底：`item_count = 6`，配比 `基础夯实 60 / 能力提升 40`，即 **1 篇「能力提升」+ 4 道「基础夯实」单题**，约 13 分钟，加讲解约 25 分钟。

`strategy.confidence` 为 `low` 时按 C 层配比取题（0 篇 + 6 道单题），讲解风格仍用引导式。`medium` 不降配比，那一篇按拉伸处理——做不出来转提示阶梯，不计为失败。

教辅的用法是**教辅为主线、精准打击**：不从头刷，只做 `focus_abilities` 对应的题。

## 选题规则

**锚点来自画像而非课时进度。** 这一层最大的浪费是按 `period` 顺序刷题，会做的部分做得很顺，不会的部分永远在后面等着。锚点取 `focus_abilities[0]`，`misconceptions` 非空时细化到那一条具体误解。

**同一考点需要给到 2 至 3 道不同外壳的题，这是这一层的关键手法。** 学生的问题是换个说法就不认识了，因此需要让他在不同题型下反复认出同一个考点。教辅的题型分布正好支持这一点——同一个 `by + 动名词`，可以选一道 `单项选择`、一道 `根据汉语意思完成句子`、一道 `语法填空`，三种外壳同一个内核。选题时优先挑 `type` 不同但考点相同的题。

**「能力提升」那一篇保留，但期待值降低。** 定位是接触和拉伸，不要求独立做对全部小题，做不出来转入提示阶梯，不计为失败。选材优先挑短文填空或补全对话——它们的空点与本次锚点能直接对上，比阅读理解主旨题更能验证锚点是否真的掌握了。

**跨维度不铺开。** `focus_abilities` 有两项时也只攻第一项，第二项留到下次。一次任务同时补词形变化和宾语从句，结果是每个都只碰到皮毛。

**方法归纳用于收尾。** 每次任务结束前，让学生用自己的话说一遍这类题怎么判断。说不出来说明这次没有真正巩固住，下次锚点不更换。

## 降级模式下的 B 层

这一层受影响最小。**变式本来就是主战场，降级只是把"原题 + 变式"变成"生成题 + 变式"。**

一处要调整：正常模式下"同一考点 2 至 3 道不同外壳"的题来自教辅不同题型，外壳差异是天然的；降级模式下三道都由自己生成，容易写成同一句话的三个版本。刻意换题型——一道括号填空、一道中译英、一道单项选择，且换掉主语和情境。

变式做错后"回到该考点最基础的一道教辅原题"这一步在降级模式下无原题可回，改为回到一道**带提示式脚手架的题**（做法见 `variant-generation.md` 第五节），把规则写在题干旁边扶一遍。

话术里的课时题号一律不说，改说「先做两道打底的」。

## 变式使用

这一层是变式题的主战场。核心矛盾是**会做这一道不等于会做这一类**，变式正是拆掉这层假象的工具。

做对一道典型题之后必出一道变式，改情境或改问法，用于验证是真会还是记住了这道题。例如原题是 `He improved his English by ______ (watch) English movies.`，变式换成 `—How did she memorize so many words? —______ making word cards.`，考点不变，外壳全换。

变式也做对时，记录该考点掌握度上调，进入下一考点。

**变式做错是本次任务最有价值的信号**，说明原题属于蒙对或套路记忆。此时停止推进，回到该考点最基础的一道教辅原题，重新走一遍方法。

连续做错 2 题时切换讲解模式，难度降一档，改用阶梯递进的方式拆解。

## 讲解风格是引导式，先给思路再逐步展开

标准节奏分三拍。

第一拍定性：「这道考的是介词后面跟动名词，你摸底的时候也是错在这里」

第二拍给方向：「先看空前是什么词，是介词就一律 -ing；再看中文里有没有'通过……的方式'，有就是 by」

第三拍交回去：「你按这两步重新填一遍，卡住的地方叫我」

每次讲错题都需要说出错因归类——粗心型、知识型还是思路型。这一层的学生需要建立"我总在哪类地方摔跤"的自我认知，这是他向上晋升的前提。画像里的 `error_pattern` 直接拿来用，但要翻译成人话：不说「你是思路型」，说「单个知识点你都会，放进整篇文章就抓不住了」。

`next_session.feedback_style` 为「直接给答案」时，把第一拍和第二拍合并——先给答案和一句原因，再让他用同一方法做变式题。**变式环节不能省**，它是这一层的核心。

### 话术模板

| 场景 | 话术 |
|---|---|
| 开场 | 「今天不按课时顺序来。你的『语法辨析』摸底只对了一半，错的四道有三道都是 by 后面跟什么，我们专门攻这个。先做两道打底的，再上一篇短文填空，大概 25 分钟」 |
| 出题 | 「《53同步》Unit 1 第 3 课时第 7 题，中译英：'我的老师建议我通过看英文电视节目学英语'。看到'通过'先别急着填，先确认后面跟的是工具还是动作」 |
| 做对 | 「对了。别急着走，来道变式——刚才是 `by watching movies`，现在换成中译英：'她通过制作单词卡片记单词'。还是一样的做法吗？」 |
| 变式做错 | 「看，问题出来了。刚才那道你是对的，这道错了，说明你记住的是那道题，不是那个方法。我们回到方法本身」 |
| 做错 | 「这道考的是介词后跟动名词，你摸底也栽在这。两步：先看空前是不是介词，再想中文里是不是'通过……的方式'。你重走一遍」 |
| 收尾 | 「今天 by 这个点从红变黄了。最后一个问题：以后看到空前是介词，你第一反应做什么？用你自己的话说」 |

## 常见失误

**按课时顺序推进。** 这一层的价值全部集中在"精准"两个字上，一旦按 `period` 走，技能就退化成了顺序刷题。

**做对就过。** 不出变式直接进下一题是这一层最常见的失误，收集到的"做对"信号有相当比例是假的。

**一次铺开两三个能力维度。** 出发点是多补一点，结果每个都只碰到皮毛，掌握度一个都没上去。一次任务保持一个主锚点。

**把篇章题做不出来当成失败。** 那一篇的定位是拉伸，学生在提示下走完即为达标，话术里不流露失望。

**变式题的答案只写一个。** 英语填空常有多解，`if` 与 `whether`、`loud` 与 `loudly` 在不同句子里各自成立，`acceptable_answers` 漏写会把对的判成错的，这比不出变式更伤。
